# 功能覆盖 · 1.0.0

| 模块 | 当前实现 |
| --- | --- |
| 导航 | 两个底部 Tab，三步试穿，独立个人页及返回 |
| 身份 | 微信 code 服务端校验、H5 OAuth、App code 入口、本机开发登录 |
| 会话 | 摘要存储、过期、轮换刷新、退出所有设备 |
| 用户隔离 | 上传/查询/生成/结果/导出/改名/收藏/删除全链路 owner 校验 |
| 资料 | 主动设置头像昵称，外形参数与自动草稿 |
| 素材 | 分类、分页、搜索、收藏、改名、删除与引用保护 |
| 人像 | 自有照片与 AI 生成，体型视觉提示与尺寸限制 |
| 试穿 | 单件/整套/连衣裙、保留服饰、上装提取、费用提示 |
| 任务 | 幂等、状态查询、页面恢复、失败提示、排队取消、结果保存 |
| 额度 | 用户/全局请求额度、独立计数、存储上限、登录/反馈限流 |
| 隐私 | 限时图片链接、退出清理设备缓存、导出、注销与后台清理 |
| 帮助 | 使用指南、反馈持久化、用户协议和隐私说明 |
| 运营管理 | 服务统计、任务状态、账号停用/恢复、反馈回复；用户查看反馈回复 |
| 运维 | Alembic、Docker、备份与恢复说明 |

未完成的发布依赖：微信资质/真实凭据/真机联调、HTTPS域名、正式运营主体协议内容、商店审核。未实现复杂工单流转、通知推送、分布式扩容；不将这些内容标记为已完成。支付按本次要求不实现。
